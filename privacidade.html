Aplicativo “rclone Gabriel”

Política de privacidade

Última atualização: 25 de setembro de 2026

1. O que é o aplicativo

“rclone Gabriel” é uma configuração de uso estritamente pessoal da ferramenta de código aberto rclone, empregada por Gabriel Arcanjo (OAB/CE 51.341) para organizar arquivos no próprio Google Drive. O aplicativo não é oferecido ao público e não possui outros usuários.

2. Dados acessados

O aplicativo acessa exclusivamente os arquivos e pastas do Google Drive da conta do próprio titular, mediante autorização concedida por ele, para listar, enviar, conferir e organizar arquivos.

3. Uso, compartilhamento e armazenamento

Nenhum dado é vendido, compartilhado com terceiros ou utilizado para publicidade. As credenciais de acesso ficam armazenadas de forma criptografada no computador do titular. O aplicativo não coleta dados de outras pessoas.

4. Uso de dados do Google

O uso de informações recebidas das APIs do Google observa a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de uso limitado.

5. Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
